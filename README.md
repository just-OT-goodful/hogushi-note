# ほぐしノート｜肩こり・腰痛セルフケア

肩こり・腰痛のセルフケアを「続けられる習慣」にするための、スマホ向けWebアプリ（PWA）です。
インストール不要・ビルド不要の静的ファイルだけで動き、GitHub Pages でそのまま公開できます。

## 機能

| やりたいこと | アプリでの機能 |
| --- | --- |
| 定期的に体を動かすようリマインド | 時刻・曜日を設定してお知らせ。カレンダー(.ics)書き出しにも対応 |
| ストレッチ・自主トレの方法を知る | 12種目。動くイラスト＋手順＋ポイント＋注意点＋回数の目安。キープタイマー／回数カウンター付き。写真・動画も追加可能 |
| セルフケアをしたことの見える化 | 今日の回数・連続日数・今週の実施日・12週カレンダー・よく行った体操 |
| 肩こり・腰痛の程度の変化の見える化 | 首・肩／腰を0〜10で記録。7・30・90日の推移グラフ、前の期間との比較、ケア直後の変化 |
| まとめてケア | 「朝のリセット」「デスクワークの合間」「寝る前の腰ケア」を順番に案内 |

- 記録はすべて **端末の中（localStorage / IndexedDB）だけ** に保存され、外部サーバーへは送信されません。
- 設定画面の「バックアップを保存・送る」で、記録をJSONファイルにできます。スマホでは共有画面が開き、ファイルアプリ・メール・LINE などに保存できます。「バックアップから復元する」で読み込めます（追加方式のため、いまの記録は消えません）。
- 初回はホームで保存についての説明を表示します。記録が5件以上あり、最後のバックアップから30日（未実施なら記録から14日）たつと、ホームでバックアップを促します。
- ブラウザに「消さないでほしい」（永続ストレージ）を要求します。自分で追加した写真・動画はバックアップに含まれません。
- **データが消える主なケース**：ブラウザのデータ削除、ホーム画面アプリの削除、機種変更、iPhone の Safari でホーム画面に追加せず約7日間開かない場合。
- 受診の目安（しびれ・排尿異常・外傷後 など）をホーム画面に掲載しています。

## リマインドについて（重要）

Webアプリは、仕様上 **アプリを閉じている間に決まった時刻で通知を出すことができません**。そのため次の2本立てにしています。

1. **アプリを開いている間**：設定した時刻にバナー（と、許可されていれば端末の通知）でお知らせ。
2. **確実に知らせたいとき**：設定画面の「カレンダー用ファイル(.ics)を保存」で、スマホ標準のカレンダーに「くり返し予定＋アラーム」として登録。

## GitHub Pages で公開する

1. このフォルダの中身をそのまま GitHub のリポジトリ（例：`selfcare-app`）に push します。
2. リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にします。
3. `main` ブランチに push すると、`.github/workflows/pages.yml` が自動で公開します。
4. 公開URL（`https://<ユーザー名>.github.io/<リポジトリ名>/`）をスマホで開きます。

> すべて相対パスなので、リポジトリ名が何でも動きます。

## スマホのホーム画面に追加する

- **iPhone**：Safari で開く → 共有ボタン →「ホーム画面に追加」
- **Android**：Chrome で開く → メニュー（︙）→「ホーム画面に追加」または「アプリをインストール」

## 写真・動画の追加

### 方法A：アプリ上から追加（ユーザー個人用）
体操の詳細画面の「写真・動画」で、端末内の写真・動画を追加できます（その端末のみに保存）。YouTube などの動画リンクも貼れます。

### 方法B：アプリに同梱する（全員に見せたい公式の動画）
1. 動画・写真を `media/` フォルダに置きます（例：`media/neck-side.mp4`）。
   - 動画は短く（10〜30秒）、スマホで撮影したものを圧縮しておくと軽くなります。
2. `js/data.js` の該当する体操の `media` を書き換えます。

```js
media: [
  { type: 'video', src: 'media/neck-side.mp4', caption: '首の横ストレッチ（正面）' },
  { type: 'image', src: 'media/neck-side-1.jpg', caption: '開始姿勢' },
],
```

3. push すれば公開されます。

## ローカルで確認する

ビルド作業は不要です。静的サーバーでこのフォルダを配信してください（`file://` では Service Worker が動きません）。

```bash
# Python がある場合
python -m http.server 8080
# Node.js がある場合
npx serve .
```

`http://localhost:8080/` をブラウザで開きます。

## 更新したあとに

`sw.js` はオフライン用にファイルをキャッシュします。**ファイルを追加・削除したときは `sw.js` の `ASSETS` を更新し、`VERSION` を上げてください。** （既存ファイルの中身だけの変更は、次回起動時に自動で反映されます。）

## ファイル構成

```
index.html            画面の骨組み
manifest.webmanifest  ホーム画面追加の設定
sw.js                 オフライン対応
css/style.css         見た目（ライト／ダーク対応）
js/data.js            体操・ルーティンのデータ ← 体操を増やすときはここ
js/app.js             画面切り替え・リマインド監視
js/store.js           記録の保存・集計
js/figure.js          動くイラスト
js/charts.js          グラフ
js/reminder.js        通知・.ics
js/views/             各画面
icons/                アプリアイコン
media/                同梱する写真・動画
```

このアプリは診断・治療の代わりにはなりません。痛みやしびれが強い場合、症状が続く・悪化する場合は、医療機関に相談してください。
